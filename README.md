# things-to-do

Landing page de videojuegos en español, con estética editorial de gran publisher y diseño adaptable a móvil. Inspiración visual general; proyecto independiente, no oficial ni afiliado a Ubisoft.

## Uso

Abre `index.html` en el navegador. No requiere dependencias ni proceso de compilación.

## Contenido

- `index.html`: página estática, estilos incluidos.
- `CALC01_SuccRecurrents.log`, `INF-G4-List.log`, `Schrodinger.log`, `GammaArtin.log`: archivos hallados al buscar «02 steam» en Drive.

> Nota: la búsqueda de Drive devolvió estos logs, pero no confirmó que pertenezcan a la carpeta «02 steam». Se conservan como archivos originales de texto y no se presentan como parte del sitio.
